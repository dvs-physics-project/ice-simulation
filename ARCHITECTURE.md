# Как устроен код симуляции

Браузерная страница без сборки: `index.html` подключает three.js 0.128 и скрипты по порядку.
Каждый файл — самостоятельный модуль, который кладёт свои функции в одно глобальное имя.
В начале каждого файла — короткое описание: что он делает и какие функции в нём есть.

## Порядок загрузки и глобальные имена

| Шаг | Файлы | Что появляется |
|---|---|---|
| 1 | `js/ice-core.js` | `ICE_CORE` — расчётное ядро (собирается в репозитории ice-core) |
| 2 | `js/shared/math.js`, `belt.js`, `geometry.js`, `materials.js`, `engine-scene.js`, `gas-effects.js`, `banks.js` | `EngineMath`, `Belt`, `Geometry`, `createMaterialLibrary`, `createEngineScene`, `GasEffects`, `CylinderBanks` |
| 3 | `js/i4/spec.js`, `js/b4/spec.js`, `js/v8/spec.js` | `EngineSpecs.i4 / b4 / v8` — размеры и кинематика |
| 4 | `js/physics.js` | `spec.physics` у каждого двигателя — давление, температура, мощность из ядра |
| 5 | `js/<двигатель>/materials.js`, `build-*.js`, `scene.js` | `EngineMaterials`, `EngineBuilders`, `EngineScenes` |
| 6 | `js/ui/profiles.js`, `charts.js`, `engine-panel.js`, `app.js` | интерфейс |

## Один двигатель — четыре слоя

```
spec.js        числа и формулы: размеры чертежа, положение поршня, подъём клапанов, ремень/шестерни
   │           (без three.js — тот же файл подключается в Node для проверок и расчётов отчёта)
physics.js     spec.physics: цикл из ядра ice-core для текущих оборотов
   │
build-*.js     детали three.js по узлам: вал, поршни, ГРМ, корпуса, навесные агрегаты, газ.
   │           Каждый строит геометрию один раз и возвращает update(crankAngle), который
   │           только переставляет детали по формулам из spec.js
scene.js       собирает узлы, задаёт свет, камеру и готовые виды, отдаёт всё в createEngineScene
```

`createEngineScene` (общий для трёх двигателей) отвечает за рендер, камеру, слои, режимы корпуса
(прозрачный, разрезы, без корпуса), выбор детали лучом и приближение к ней.

## Один кадр

1. `app.js` вызывает `frame(now)` у открытой панели (`engine-panel.js`).
2. Панель переводит прошедшее время в угол вала с учётом оборотов и замедления показа.
3. `engine.update(угол)` → `update` каждого узла: вал поворачивается, поршни встают на
   `spec.pistonPosition`, клапаны — на подъём из spec.js (у B4 и V8 — через угол коромысла), ремень сдвигается на дугу шкива,
   газ берёт давление и температуру из `spec.physics.stateAt`.
4. Панель обновляет показания цилиндра и маркеры на графиках (`charts.js`).

## Проверки

- `node tools/verify-physics.js` — 58 проверок, что модель показывает расчёт ядра (без браузера).
- `PHYSICS.md` — откуда берётся каждое число на экране и какие допущения сделаны.
